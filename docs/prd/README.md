# PRDs

This directory holds Product Requirement Docs. One file per user-facing feature.

Filename convention: `PRD-<topic>.md` (kebab-case, descriptive). Examples:

- `PRD-bulk-import.md`
- `PRD-payment-failure-recovery.md`
- `PRD-multi-tenant-routing.md`

PRDs are owned by **PM Agent**. See `.claude/agents/pm-agent.md` for the canonical PRD shape and authoring workflow.

Bug fixes, refactors, chores, and hotfixes do NOT require a PRD. See `SDLC.md` Step 0 for the gate.
